# Motion language

The motions that made these formats feel dense and finished. Each one is in at least one starter.

| Motion | What it does | Where |
|---|---|---|
| Slam word | One key word per line lands huge in the accent colour with a small overshoot | faceless explainer, talking head |
| Word-by-word captions | The current word lights up in the accent | all reels |
| Layout switch | Face, split (graphic over face) and full graphic, changing on spoken words | talking head |
| Camera move on a screenshot | Slow push and pan across a real UI, with a highlight box drawn on the key part | animated explainer, talking head |
| Counter or odometer | Numbers keep ticking, never resting | animated explainer, reference remake |
| Bar race and growing bars | Data that moves | faceless explainer, reference remake |
| Cards fly in and land | Cards arc in, land with a small bounce and a thock | reference remake |
| Debris burst | Small shapes burst on an impact | reference remake, game parody |
| Highlight box behind a caption word | A marker box sweeps behind one word | reference remake |
| Orbit of logos | Tool logos circle a centre | animated explainer (news) |
| Stamp | A "done" or "posted" badge stamps on with a shake | game parody, animated explainer |

## Timing rules
- A new visual every 1–2 s in talking heads, every 2–4 s in faceless explainers.
- Each animation gets about 2 s to read. An orbit at 0.7 s was too short to register.
- Key every motion to a spoken word, never to a hand-picked time.
- Land the end state of every animation before the next beat starts.
